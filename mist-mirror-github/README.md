# 雾镜 MIST · GitHub Pages 版 - 基于小饼干🍪lilian.chiuuu

一个能在浏览器中使用的雾镜。摄像头实时镜像，麦克风估计吹气力度，食指擦雾写字，拇指与食指捏合抬笔，支持画笔粗细调节和 PNG 拍照下载。

这是完整独立网站 https://vhg6zte.github.io/mist-mirror/mist-mirror-github/docs/

## 使用方法

1. 在系统浏览器打开最终的 HTTPS 网站，点击「开启雾镜」，允许摄像头和麦克风。
2. 安静约 2 秒，让页面校准底噪，然后朝麦克风轻轻哈气。摄像头与麦克风可能位于不同位置。哈气声越强，雾气增长越快。
3. 让整只手进入摄像头，伸直食指写字；拇指与食指捏合时抬笔，移动到下一笔起点后松开，继续书写。
4. 调整笔画粗细，点击「拍下此刻」，预览后下载 PNG。

也可以先体验：使用鼠标按住拖动、触屏书写，按住「模拟一口呼吸」起雾。关闭摄像头时，麦克风会一起关闭。
