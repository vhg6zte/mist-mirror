A SMALL GUIDE

跟雾镜打个招呼。

  1. 打开镜头

    点击「开启雾镜」，允许摄像头和麦克风。拒绝麦克风也能写字，点击模拟呼吸即可起雾。

  2. 把呼吸变成雾

    先安静 2 秒完成校准，再靠近麦克风轻轻吹气。强度由声音的音量与频谱估计，不是气流实测；说话、风扇也可能触发，可重新校准和调整灵敏度。

  3. 食指写，捏合停

    让整只手进入镜头，伸直食指开始写字。拇指与食指捏合时抬笔，保持捏合可移动到下一笔起点，松开且伸直食指继续。也可以按暂停，或按住鼠标 / 触屏拖动写字。

  4. 拍下此刻

    照片会保留镜面与笔迹，不含手势光标。预览照片后下载 PNG，不会上传。

建议在明亮环境使用，手离镜头约 30–80 cm。摄像头与麦克风位置可能不同，请朝麦克风哈气。浏览器需要支持摄像头权限；微信内打不开时可在系统浏览器尝试。
